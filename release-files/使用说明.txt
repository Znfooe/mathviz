============================================================
  数学之美 · 交互式数学可视化平台  v1.0.0
  使用说明
============================================================

【这是什么】
  一个交互式数学实验平台，包含 65+ 个可动手操作的数学实验：
  极坐标曲线、三角函数、泰勒展开、线性代数、蒙特卡洛、
  马尔可夫链、黄金分割、热传导方程……
  拖动滑块即可实时改变参数，图形当场变化，适合课堂演示
  和自主探索。

【系统要求】
  · Windows 10/11、macOS 11+ 或主流 Linux
  · 已安装 Node.js（LTS 版，免费）
    下载地址：https://nodejs.org/  （安装一路"下一步"即可）
  · 不需要联网，不需要安装其他任何软件

------------------------------------------------------------
【Windows 用户】
  双击 「启动平台-Windows.bat」
  → 浏览器会自动打开平台
  → 关闭黑色命令行窗口即停止平台

【macOS 用户】
  打开"终端"，进入本文件夹，执行：
    chmod +x start.sh
    ./start.sh

【Linux 用户】
  在本文件夹下执行：
    chmod +x start.sh
    ./start.sh
------------------------------------------------------------

【常见问题】

  Q: 双击后提示"未检测到 Node.js"？
  A: 请先到 https://nodejs.org/ 下载安装 LTS 版本，
     安装完成后重新双击启动。

  Q: 浏览器没有自动打开？
  A: 手动打开浏览器，访问黑色窗口中显示的地址，
     通常是 http://localhost:8088

  Q: 8088 端口被占用？
  A: 平台会自动换用 8089、8090……，以窗口中显示的
     实际地址为准。

  Q: 想在学校服务器上部署给全校用？
  A: 把本文件夹里的 web 目录整个上传到任意网站服务器
     （nginx / 宝塔 / IIS 均可），它是纯静态网站，
     不需要 Node.js 和数据库。

【完整版与轻量版的区别】
  完整版含 AI 语音讲解音频（约 600MB）；
  轻量版不含语音（约 12MB），其余功能完全相同。

【自动更新】
  平台启动后会在后台自动检测新版本（可在左下角"检测更新"
  手动检查）。发现新版后可后台下载，不影响正常使用；
  下载完成点击"立即安装"，按提示操作即可。
  安装过程约几秒到十几秒，期间请勿关闭平台窗口、
  请勿断开电源，否则可能导致文件缺失而无法启动。
  安装完成后按提示关闭窗口、重新双击启动即为新版。
  （更新只下载约 12MB 的轻量包，已有的语音音频不会受影响。）
